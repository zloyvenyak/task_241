# Ключики

1. Что такое ssh ключи и зачем они нужны?<br>
SSH‑ключи — это пара криптографических ключей (приватный + публичный) для аутентификации в SSH без передачи пароля по сети и для удобного “passwordless” входа.
2. Как их создать?<br>
Используется ssh-keygen (на клиентской машине).
3. Создайт пару публичный/приватный ключ ed_25519, где они хранятся?<br>
![img_8.png](img_8.png)<br>
- Приватный: ~/.ssh/id_ed25519
- Публичный: ~/.ssh/id_ed25519.pub
4. Скопируйте публичный ключ на ваш сервер, в каком файле он будет храниться?<br>
![img_9.png](img_9.png)<br>
На сервере ключ добавится в файл: `~/.ssh/authorized_keys`
5. Попробуйте подключиться к серверу, у вас запросили пароль?<br>
Нет, пароль не запросили.<br>
![img_10.png](img_10.png)
6. Запретите подключение с паролем для всех пользователей, оставьте только с помощью ключа.<br>
![img_11.png](img_11.png)<br>
`PasswordAuthentication no` отключает вход по паролю.
